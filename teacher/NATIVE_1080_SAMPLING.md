# 原生尺寸采样(max side 1080)

2026-10-21 产品侧确定的训练采样规则。目标是让**训练时的场尺寸与部署时一致** ——
此前的训练样本都是 320×512 裁剪,而部署(引擎 / `render_samples.py`)是整图原生尺寸
一次前向,实测两者差约 2.3 dB(同批 64 张图:裁剪口径 33.2 dB,整图口径 30.9 dB)。

## 规则

对每张图为 `(w, h)`,上限 `native_max_side`(默认 **1080**):

```
若 max(w, h) <= 1080:
    → 整图直接送入,不缩放、不裁剪              (S 分支)

否则,若该图有 ROI(人脸框):
    → 等概率二选一(native_ab_split,默认 0.5)
      A:等比缩放,使最大边 = 1080
      B:以人脸中心为中心、保持原图宽高比、
        最大边 = 1080 的框做裁剪

否则(无 ROI):
    → 只做 A
```

三条分支都保持宽高比,不产生形变。已在限内的图**不会被放大**,保留原始细节。

### 示例(1920×1080,人脸框 `[800,300,1100,600]`)

| 分支 | 输出尺寸 | crop box |
| --- | --- | --- |
| A | 1080×608 | — |
| B | 1080×608 | `[410, 146, 1490, 754]`(人脸中心 950,450) |
| 无脸 | 1080×608 | — |

## 配置

```json
"native_max_side": 1080,
"native_ab_split": 0.5,
"sampling": {"native1080": 1.0, "roi_native": 0, "random_native": 0,
             "scaled_crop": 0, "context": 0}
```

`sampling` 里其余模式的权重可以混用(例如 `native1080: 0.7` + `scaled_crop: 0.3`),
`mode_prob` 会按权重归一化。旧配置里没有 `native1080` 键时该权重按 0 处理,不影响既有 run。

配置示例见 `remote/run_cnn_fast_a100_native1080.json`。

## 显存与 batch_rows

`batch_rows` 决定单个 microbatch 的行数上限,而代码会**拒绝**任何 `full_rows`
超过 `min(batch_rows, teacher_batch_rows)` 的样本,所以它必须 ≥ 最大样本行数。

| 场尺寸 | full_rows（含补齐） | 建议 |
| --- | ---: | --- |
| 1080×608(16:9 大图) | 737,280 | 3090 可跑 |
| **1080×1080(方图)** | **1,327,104** | **24 GB 卡会 OOM**,A100 40/80 GB 可跑 |

注意 `full_rows` 是**补齐后**的行数(`geometry_from_valid` 会把宽高向上取整到
对齐单位),比 `w×h` 大 10% 左右。1080×1080 对应补齐后的 1152×1152 = 1,327,104 行,
所以 A100 配置用 `batch_rows = 1,400,000`、`batch = 4`。

实测参考(3090,`cnn_unet_fast`,batch 8 在 320×512 下每块 3 张 ≈ 491k 行):
峰值 15.6 GB、1.8 s/步。行数近似线性放大,可按 `峰值 × (新行数 / 491520)` 估算。

## 验证

1. 冒烟:样本尺寸应全部 ≤ 1080,且不出现形变
   ```bash
   python3 teacher/train_distill_single.py --config <cfg> --steps 2 --batch 1 --val-count 1 -o <tmp>
   ```
   日志里 `data: ... files` 之后若出现 `training field exceeds configured row budget`,
   说明 `batch_rows` 不够大。
2. 分布抽查:对 `native1080` 分支,统计输出尺寸的直方图,应与"数据集尺寸经 A/B 处理"
   的预期一致(例如 1920×1080 的图只应出现 1080×608)。

## 为什么这样做

七组消融(数据量 / 辅助损失 / 归一化 / FFN 组织 / 最深下采样 / 主干容量)都没有突破
31 dB,而**裁剪口径与整图口径之间稳定存在 2.3 dB 差距**,且该差距不随架构变化。
把训练场尺寸对齐部署场尺寸,是目前唯一有实测证据支持的方向。
